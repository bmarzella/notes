# The Performance Triad

![[Pasted image 20261006122834.png]]

- Used to measure how fast a processor executes a program:












$$
CPU \space Time =\frac{Instructions}{Program} \times \frac{Cycles}{Instruction} \times \frac{Time}{Cycle}
$$
