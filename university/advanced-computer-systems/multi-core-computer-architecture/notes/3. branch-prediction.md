# Branch Prediction
Instead of delaying or relying on branch relay slots, modern processors use **Branch Prediction** There are two types: 

**Static/Compile Time Branch Prediction**
Fixed rules are determined before the code is run. For example:
- Always predict "Branch Not Taken"
- Predict backwards branches taken for loops
- etc...

## Dynamic Branch Prediction

To predict branch outcome on the fly, we need a **history table**.

>**Branch History Table (BHT):** *Stores the outcome of each branching decision as a `0` (not taken) or `1` (taken). Indexed by the lower portion of the address of the branch instruction.*
